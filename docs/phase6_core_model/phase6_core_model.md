## 3. Design Decisions Taken in Phase 6

| # | Decision | Evidence | Approval |
|---|---|---|---|
| D-1 | **Snapshot built in Phase 6 in `core`**, not Phase 7 in `analytics`. The Implementation Plan places release-collapse logic in Phase 6, and Gate B needs a duplicate/release reconciliation. Phase 7 now builds only the metric-eligibility views. | Phase 4 §6.3 conflicted with the Implementation Plan | Project owner, 2026-10-07 |
| D-2 | **`dim_supplier` = supplier-role parties ∪ award suppliers.** Phase 4 specified parties only. | 1,137 awards have no supplier party in their release; 29 supplier IDs appear only on awards (EN-07/08). A parties-only dimension would leave RI-12 orphans. | Within approved identity rule (source ID, no merging) |
| D-3 | **`dim_buyer.buyer_id_flag = 'INCOMPLETE'`** for the bare `NG-BPP-` buyer ID. Retained as its own row, never re-assigned. | 26 releases (19 with no parties at all); no buyer party to recover from (EN-03) | **Proposed as DQ-19, requires approval** (§6) |
| D-4 | **Name rule for dimensions:** the most frequent published name per ID (trimmed for comparison), ties broken by the latest release; the raw value is stored as published, and a whitespace-standardised version is generated. | Buyer: 0 IDs with >1 release-level name (EN-04). Supplier: 1,483 IDs with >1 name (DQ-13); `name_variant_count` records this per ID. | Within DQ-13/15 (display only, no merging) |
| D-5 | **No declared FKs from staging to core.** Integrity is enforced by validation instead (RI-11 to RI-15). | A declared FK would make rebuilding a dimension cascade into truncating staging | Design note |

## 4. Release Collapse: Double Counting Removed

| Measure | All releases (would double count) | Snapshot | Difference |
|---|---|---|---|
| Award value (NGN) | 4,719,623,321,230.60 | 4,383,632,505,475.12 | −335,990,815,755.48 (−7.1%) |
| Budget (NGN, incl. EXTREME) | 206,066,299,972,578.47 | 190,269,651,068,904.93 (97,749 budget lines) | −15,796,648,903,673.54 |

Both snapshot totals were re-derived with an independent SQL formulation
(NOT EXISTS a later release) and match to the kobo (RL-06, RL-09). The
budget-line total excluding EXTREME is ₦93,827.8bn, matching the Phase 4.1
evidence (RL-05).
